1 Pengertian Dasar HTML & Filosofinya

HTML (HyperText Markup Language) adalah bahasa standar penandaan (*markup*) yang digunakan untuk membuat dan menyusun struktur dasar dari sebuah halaman web. Perlu dipahami oleh siswa bahwa HTML bukanlah bahasa pemrograman (karena tidak memiliki logika seperti perulangan atau pengondisian), melainkan **bahasa struktur/fondasi**.

Analogi terbaik untuk memahami HTML adalah **Kerangka Manusia** atau **Kerangka Bangunan**. HTML menentukan di mana letak judul, paragraf, gambar, dan tombol. Tanpa HTML, browser tidak tahu bagaimana cara menampilkan informasi secara teratur.

📑

A. Tag Heading (`

` - `

`)

Pengertian: Tag khusus yang digunakan untuk mendefinisikan judul utama dan sub-judul berjenjang dalam sebuah dokumen HTML.

Fungsi: Memberikan tingkatan/hirarki visual dan struktur informasi dari derajat terbesar (<h1>) sampai terkecil (<h6>).

💡 Kegunaan Relevan:
  • Kemudahan Membaca (UX): Pembaca web bisa melakukan scanning judul dengan cepat.
  • SEO (Search Engine Optimization): Mesin pencari seperti Google menggunakan <h1> untuk memahami topik utama halaman web.
✍️

B. Pemformatan Teks

Pengertian: Kumpulan tag HTML yang bertugas mengubah tampilan atau memberikan penekanan makna pada kata/kalimat di dalam paragraf.

Fungsi: Menandai teks agar tebal (<b>/<strong>), miring (<i>/<em>), bergaris bawah (<u>), atau diberi stabilo (<mark>).

💡 Kegunaan Relevan:
  • Penekanan Informasi: Menarik perhatian pembaca pada poin kunci/kata penting.
  • Istilah Asing: Tag <i> digunakan sesuai kaidah bahasa untuk istilah bahasa asing atau jargon teknis.
🔗

C. Tag Hyperlink (``)

Pengertian: Tag Anchor yang berfungsi menghubungkan satu dokumen HTML dengan dokumen HTML lainnya, atau ke situs eksternal.

Fungsi: Menyediakan elemen interaktif (teks/tombol) yang jika diklik akan mengarahkan pengguna ke alamat URL atau lokasi file tujuan.

💡 Kegunaan Relevan:
  • Navigasi Situs: Tanpa hyperlink, web hanya berupa file terisolasi. Hyperlink menjadikan jutaan halaman web menjadi jaringan **World Wide Web**.
  • Interaktivitas Antar Halaman: Memungkinkan pembuatan menu navigasi seperti *Beranda*, *Profil*, dan *Kontak*.

Berikut adalah panduan teknis penulisan sintaks kode beserta simulasi langsung hasil penampilannya di dalam layar browser.

Perhatikan bagaimana ukuran teks mengecil secara otomatis dari H1 hingga H6.

<h1>Judul Tingkat 1 (paling besar)</h1> <h2>Sub-Judul Tingkat 2</h2> <h3>Sub-Judul Tingkat 3</h3> <h4>Sub-Judul Tingkat 4</h4> <h5>Sub-Judul Tingkat 5</h5> <h6>Sub-Judul Tingkat 6 (paling kecil)</h6>

2. Contoh Tag Pemformatan Teks

Tag pemformatan biasanya diletakkan di dalam tag paragraf (<p>).

Kode HTML:
<p> Ini adalah kata <b>Tebal</b> dan kata <strong>Sangat Penting</strong>.<br> Ini adalah kata <i>Miring (Italic)</i> untuk bahasa asing.<br> Ini adalah kata bergaris <u>Bawah (Underline)</u>.<br> Ini adalah teks dengan <mark>Stabilo / Highlight</mark>. </p> <hr> <p> Kombinasi: <b><i><u>Tebal, Miring & Garis Bawah</u></i></b> sekaligus. </p>
Tampilan di Browser:

Ini adalah kata Tebal dan kata Sangat Penting.
Ini adalah kata Miring (Italic) untuk bahasa asing.
Ini adalah kata bergaris Bawah (Underline).
Ini adalah teks dengan Stabilo / Highlight.

Kombinasi: Tebal, Miring & Garis Bawah sekaligus.

3. Contoh Tag Hyperlink (``)

Perhatikan penggunaan atribut href="..." sebagai penentu lokasi tujuan.

Kode HTML:
<!-- Link Internal (Ke file lain dalam folder proyek) --> <p> Buka <a href="profil.html">Halaman Profil Saya</a> </p> <!-- Link Eksternal (Ke situs web luar) --> <p> Kunjungi <a href="https://google.com" target="_blank">Google Search</a> </p>
Tampilan di Browser:

Buka Halaman Profil Saya

📌 Mengarahkan ke file lokal profil.html

Skenario Pembelajaran

Studi Kasus: Website Portofolio UMKM Digital

Sebuah toko roti lokal bernama "Roti Lezat Pak Ahmad" ingin memiliki website sederhana. Mereka membutuhkan 2 halaman: Halaman Beranda (menampilkan nama toko, moto, dan produk unggulan) serta Halaman Kontak (menampilkan alamat dan biodata pemilik).

📋 Persyaratan Teknis Website UMKM:

  • Gunakan <h1> untuk nama toko di halaman utama.
  • Gunakan <mark> untuk menyorot kata promo atau harga diskon.
  • Gunakan pemformatan <b> dan <i> pada nama varian roti (misal: istilah bahasa asing seperti Croissant).
  • Buat Hyperlink yang menghubungkan index.html (Beranda) dan kontak.html (Halaman Kontak).

Tugas Pertemuan 1

Latihan Pemformatan Teks & Heading

  1. Buat file baru bernama latihan1.html.
  2. Tuliskan judul utama dengan <h1> berisi nama lengkapmu.
  3. Tuliskan sub-judul dengan <h2> tentang Cita-Cita.

  5. Pastikan ada minimal 1 kata tebal (<b>), 1 kata miring (<i>), dan 1 kata bersorotan (<mark>).
Tugas Pertemuan 2

Proyek Mini: Website 2 Halaman

  1. Buat folder bernama web-biodata di komputermu.
  2. Di dalam folder tersebut, buat file index.html dan hobi.html.
  3. Pada index.html, buat menu link menuju hobi.html.
  4. Pada hobi.html, buat link navigasi untuk kembali ke index.html.
  5. Uji coba klik link di browser hingga berhasil berpindah halaman tanpa error 404!
