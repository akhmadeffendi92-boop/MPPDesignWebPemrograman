1. Konsep Client-Server & HTML

Apa itu Client-Server?

Arsitektur jaringan yang memisahkan tugas antara penyedia layanan (**Server**) dan peminta layanan (**Client**). Dalam dunia web, Client adalah web browser (Chrome, Firefox) dan Server adalah komputer yang menyimpan file website (Apache, Nginx).

Apa itu HTML?

**Hypertext Markup Language**. Bukan bahasa pemrograman, melainkan bahasa markah untuk menyusun kerangka sebuah halaman web. Bayangkan HTML sebagai "tulang" pada tubuh manusia.

⚙️ Fungsi dan Kegunaan

Penyajian Informasi

Menampilkan data terstruktur (teks, gambar, link) agar bisa dibaca manusia melalui browser.

Sentralisasi Data

Server menyimpan data di satu tempat agar ribuan client bisa mengakses informasi yang sama secara bersamaan.

Interaksi Jaringan

Memungkinkan komunikasi antar perangkat di jaringan lokal (Intranet) maupun global (Internet).

2. Analisis Teknis & Industri

✅ Kelebihan

  • • Skalabilitas: Server bisa ditingkatkan spesifikasinya (Upgrade RAM/CPU) tanpa mengubah Client.
  • • Keamanan: Kontrol data dipusatkan di Server, sehingga lebih mudah diawasi.
  • • Standarisasi: HTML didukung oleh semua browser di dunia secara gratis.

❌ Kekurangan

  • • Single Point of Failure: Jika server down, semua client tidak bisa mengakses layanan.
  • • Biaya Operasional: Memelihara server 24/7 membutuhkan listrik dan pendingin yang stabil.
  • • Ketergantungan Jaringan: Tanpa koneksi (HTTP), aplikasi web tidak dapat berfungsi.

KASUS #1

Kegagalan DNS Sekolah

"Siswa bisa membuka web sekolah dengan mengetik IP 10.20.30.1, tapi gagal saat mengetik smkn1tanjung.sch.id."

Tugas Kelompok:

Identifikasi pada bagian mana alur Client-Server ini terputus? Berikan solusi teknisnya.

KASUS #2

The "Ghost" Content

"Siswa sudah mengetik tag <h1> di dalam file HTML, namun saat dibuka di browser, layarnya putih bersih tanpa tulisan apapun."

Tugas Kelompok:

Analisis kemungkinan kesalahan penulisan tag (Sintaks) yang terjadi. Tunjukkan struktur yang benar!

KASUS #3

Server Load Balancing

"Saat hari pendaftaran PPDB, website sekolah sangat lambat dibuka karena ribuan wali murid mengakses secara bersamaan."

Tugas Kelompok:

Sebutkan 3 cara untuk meningkatkan kemampuan Server agar tetap stabil menghadapi trafik tinggi!

KASUS #4

Head vs Body Logic

"Seorang siswa meletakkan foto profil sekolah di dalam tag <head>, namun foto tersebut tidak muncul di halaman web."

Tugas Kelompok:

Jelaskan mengapa hal itu terjadi berdasarkan fungsi teknis tag <head> dan <body>.

KASUS #5 (UTAMA)

Troubleshooting HTTP Status

"Admin jaringan sekolah melihat log server menunjukkan banyak error status 403 Forbidden dan 500 Internal Server Error."

Tugas Kelompok:

Cari tahu perbedaan makna kode 403 dan 500. Mana yang kesalahan Client dan mana yang kesalahan Server?

Implementasi:

Tuliskan kode HTML sederhana untuk membuat halaman "Under Maintenance" milik sekolah.
