Konsep Dasar Gambar dalam Web Development

Gambar adalah salah satu komponen multimedia terpenting pada halaman web. Tanpa gambar, sebuah situs web akan terasa kaku dan membosankan. Gambar tidak hanya berfungsi sebagai elemen hiasan (dekoratif), tetapi juga sebagai penyampaian informasi visual, identitas merek (branding), daya tarik UX (User Experience), serta memperkuat struktur konten.

Agenda Pertemuan 1 (4 JP / 180 Menit)

  • Memahami prinsip kerja HTTP request pada elemen media gambar.
  • Menguasai Tag utama <img> dan Atribut Wajibnya (src, alt, title).
  • Membedakan Jalur Berkas (Relative vs Absolute Path).
  • Mengatur Dimensi Gambar (width & height) & Pengaruhnya terhadap CLS (Cumulative Layout Shift).
  • Mengenal Format Gambar Web Modern (JPEG, PNG, GIF, SVG, WebP, AVIF).

Agenda Pertemuan 2 (4 JP / 180 Menit)

  • Menggunakan Tag Semantik HTML5: <figure> & <figcaption>.
  • Penyajian Gambar Responsif dengan Tag <picture> & <source>.
  • Membuat Area Gambar Interaktif (Image Mapping: <map> & <area>).
  • Manipulasi Visual CSS: object-fit, border-radius, box-shadow, filter, dan efek Hover.
  • Optimasi Performa: Atribut loading="lazy".

Penjelasan Detail Tag HTML & Atribut Gambar

<img>

Tag Utama Gambar (Void Element / Self-Closing)

Tag <img> digunakan untuk menyisipkan gambar ke dalam dokumen HTML. Tag ini bersifat Inline Element (berada sejajar dengan teks) dan merupakan Void Element (tidak memiliki penutup seperti </img>). Tag ini menyisipkan gambar secara tidak langsung dengan mereferensikan sumber berkas gambar.

Nama Atribut / Tag Jenis / Nilai Fungsi & Detail Operasional Relevansi & Best Practice
src (source) URL / File Path Menentukan jalur alamat berkas gambar. Bisa berupa Relative Path (lokal) atau Absolute Path (URL web lain). Wajib Ada. Jika path salah, gambar akan rusak (broken image).
alt (alternate text) String / Teks deskriptif Teks pengganti jika gambar gagal dimuat. Sangat krusial untuk Screen Reader (aksesibilitas difabel netra) dan Web Crawler (SEO). Sangat Wajib untuk Aksesibilitas & SEO. Jangan dikosongkan kecuali gambar murni dekoratif (alt="").
title String / Teks singkat Menampilkan balon petunjuk (tooltip) saat kursor mouse diuji usap (hover) di atas gambar. Memberikan informasi tambahan non-krusial bagi pengguna desktop.
width & height Pixel (angka) Menentukan lebar dan tinggi gambar dalam satuan piksel pada HTML. Menyiapkan ruang sebelum gambar termuat sempurna. Mencegah Cumulative Layout Shift (CLS) agar konten web tidak melompat-lompat saat memuat.
loading "lazy" | "eager" Pengaturan pemuatan gambar. lazy menunda pemuatan gambar sampai mendekati area layar (viewport). Meningkatkan kecepatan muat halaman web (Page Speed) secara drastis.
<figure> & <figcaption> Semantic Container Tag <figure> membungkus gambar beserta penjelasannya, sedangkan <figcaption> memberikan keterangan/caption gambar. Menjadikan struktur dokumen HTML lebih rapi, terstruktur, dan dipahami oleh mesin pencari.
<picture> & <source> Responsive Image Tag Wadah untuk menyajikan berbagai variasi gambar berdasarkan ukuran layar (media query) atau dukungan format modern. Penting untuk Responsive Web Design (RWD) & optimasi hemat kuota pengguna mobile.
<map> & <area> Image Mapping Membuat wilayah klik interaktif pada gambar tunggal menggunakan koordinat posisi (rect, circle, poly). Digunakan untuk denah lokasi, struktur organ tubuh, diagram interaktif, atau peta wilayah.

Perbandingan Format Gambar Web Modern

JPG / JPEG
Fotografi Realistis

Kompresi lossy. Cocok untuk foto alam/manusia dengan gradasi warna tinggi. Tidak mendukung latar transparan.

PNG
Transparansi & Grafik

Kompresi lossless. Sangat baik untuk logo, ikon, diagram, dan gambar dengan Latar Belakang Transparan (Alpha Channel).

SVG
Vektor Bebas Pecah

Format berbasis XML. Tidak akan pernah pecah meski di-zoom pada layar Retina/4K. Ukuran berkas sangat kecil.

WebP / AVIF
Format Web Masa Depan

Format kompresi sangat tinggi buatan Google/AOMedia. Ukuran berkas 30-50% lebih kecil dibanding PNG/JPG tanpa mengurangi kualitas.

Contoh Penerapan Implementasi Kode Per Tag & Atribut

Pelajari sintaks spesifik dan struktur kode HTML beserta penjelasannya untuk setiap kasus penggunaan.

Tag <img> Dasar dengan Atribut Wajib (src, alt, title) Pertemuan 1

KODE HTML:

<!-- Menggunakan Relative Path -->
<img src="images/pemandangan.jpg" 
     alt="Pemandangan Danau Toba saat matahari terbit" 
     title="Matahari Terbit di Danau Toba">

<!-- Menggunakan Absolute Path -->
<img src="https://images.unsplash.com/photo-1507525428034-b723cf961d3e" 
     alt="Pantai pasir putih berair jernih" 
     title="Pantai Tropis">
Penjelasan Pengerjaan:

• src="images/pemandangan.jpg": Sistem mencari file di dalam sub-folder images relatif terhadap tempat file HTML disimpan.

• alt="...": Jika koneksi internet terputus atau file terhapus, pembaca layar akan membacakan deskripsi ini.

• title="...": Arahkan kursor mouse ke gambar di browser, maka akan muncul teks kecil melayang (tooltip).

Pengaturan Dimensi (width, height) & Lazy Loading Pertemuan 1

KODE HTML:

<img src="assets/gedung.jpg" 
     alt="Gedung Rektorat Kampus" 
     width="600" 
     height="400" 
     loading="lazy">
Penjelasan Pengerjaan:

• Pada HTML5, penulisan width="600" dan height="400" ditulis sebagai angka murni (tanpa embel-embel 'px').

• Mengatur atribut dimensi ini menjaga aspek rasio gambar dan mencegah efek pergeseran tata letak halaman saat gambar dimuat (Penting untuk skor Google Lighthouse / Core Web Vitals).

• loading="lazy" membuat browser menunda pemuatan gambar jika lokasi gambar berada jauh di bawah gulir layar pengguna.

Struktur Semantik <figure> dan <figcaption> Pertemuan 2

KODE HTML:

<figure class="foto-artikel">
  <img src="kura-kura.jpg" alt="Kura-kura hijau berenang di laut">
  <figcaption>
    Gambar 1.2: Spesies Kura-Kura Hijau di Kepulauan Derawan. 
    <small>(Foto: Dokumentasi Taman Nasional)<small>
  </figcaption>
</figure>
Penjelasan Pengerjaan:

• Elemen <figure> menandakan bahwa konten gambar beserta teksnya adalah satu kesatuan unit informasi yang independen.

• Elemen <figcaption> diletakkan di dalam <figure> (bisa di atas atau di bawah tag gambar) untuk memberi keterangan caption resmi.

Gambar Responsif dengan <picture> dan <source> Pertemuan 2

KODE HTML:

<picture>
  <!-- Layar Desktop (>= 1024px) -->
  <source media="(min-width: 1024px)" srcset="banner-wide.webp">
  
  <!-- Layar Tablet (>= 640px) -->
  <source media="(min-width: 640px)" srcset="banner-medium.webp">
  
  <!-- Fallback Default / HP Mobile -->
  <img src="banner-mobile.jpg" alt="Hero Banner Utama">
</picture>
Penjelasan Pengerjaan:

• Tag <picture> memungkinkan kita melakukan Art Direction (menyajikan foto cropped/berbeda tergantung ukuran layar HP atau Komputer).

• Browser mengevaluasi atribut media="..." dari atas ke bawah. Tag <img> wajib ada di paling bawah sebagai cadangan jika tidak ada kondisi yang terpenuhi.

Image Map Interaktif (<map> dan <area>) Pertemuan 2

KODE HTML:

<!-- Atribut usemap mereferensikan nama map -->
<img src="peta-indonesia.jpg" usemap="#petaindo" alt="Peta Indonesia">

<map name="petaindo">
  <!-- Area Persegi (x1, y1, x2, y2) -->
  <area shape="rect" coords="30,50,150,200" href="sumatera.html" alt="Sumatera">
  
  <!-- Area Lingkaran (centerX, centerY, radius) -->
  <area shape="circle" coords="300,150,40" href="jawa.html" alt="Jawa">
</map>
Penjelasan Pengerjaan:

• Atribut usemap="#petaindo" menghubungkan elemen gambar dengan tag <map name="petaindo">.

• Tag <area> menentukan titik koordinat yang dapat diklik. Jenis bentuk (shape) bisa berupa rect (persegi), circle (lingkaran), atau poly (poligon segi banyak).

Pengaturan Atribut Visual CSS Gambar Pertemuan 2

KODE CSS:

.gambar-produk {
  width: 100%;
  height: 250px;
  /* Menjaga proporsi tanpa gepeng/distorsi */
  object-fit: cover; 
  object-position: center;
  border-radius: 12px;
  box-shadow: 0 4px 6px rgba(0, 0, 0, 0.1);
  filter: grayscale(30%);
  transition: all 0.3s ease;
}

.gambar-produk:hover {
  filter: grayscale(0%);
  transform: scale(1.05);
  box-shadow: 0 10px 15px rgba(0, 0, 0, 0.2);
}
Penjelasan Pengerjaan:

• object-fit: cover: Properti CSS terpenting agar gambar otomatis terpotong rapi menyesuaikan kotak tanpa tertarik atau terdistorsi gepeng.

• filter: Memberikan efek visual langsung seperti grayscale, blur, brightness, atau sepia.

• transition & :hover: Membuat efek animasi visual interaktif yang mulus saat kursor pengguna melintas di atas gambar.
