1. Pengertian Tabel Data dalam HTML

Dalam dunia pemrograman web, **Tabel Data (Data Table)** adalah elemen visual yang digunakan untuk menyajikan informasi terstruktur yang terdiri dari baris (*rows*) dan kolom (*columns*). Penggunaan tabel sangat ideal untuk data yang memiliki hubungan dua dimensi, seperti laporan keuangan, jadwal pelajaran, daftar inventaris barang, perbandingan spesifikasi produk, maupun rekapitulasi nilai siswa.

Secara historis pada era HTML awal (HTML4), tabel sering disalahgunakan untuk merancang tata letak (*layout*) seluruh halaman web. Namun, pada standar **HTML5 modern**, tabel **hanya boleh digunakan untuk menyajikan data tabular**. Untuk tata letak web, pengembang wajib menggunakan elemen CSS Layout seperti Flexbox atau CSS Grid. Penggunaan tabel yang benar sangat krusial demi menjaga standar semantik web, optimasi SEO (Search Engine Optimization), dan aksesibilitas bagi pengguna dengan disabilitas (*screen reader*).

2. Anatomi & Fungsi 4 Komponen Utama Tabel

Penyusunan tabel HTML didasarkan pada tata susunan hirarki bertingkat. Berikut adalah penjelasan mendalam mengenai 4 elemen dasar pembentuk tabel:

<table>

1. Tag <table> (Elemen Pembungkus Utama)

Tag <table> bertindak sebagai kontainer paling luar (*outer envelope*) yang menandai awal dan akhir dari suatu blok tabel data pada dokumen HTML.

  • Fungsi Utama: Memberitahu browser bahwa semua elemen di dalamnya adalah bagian dari struktur tabel.
  • Atribut Terkait (Klasik vs Modern): Dahulu menggunakan atribut seperti border="1", cellpadding, dan cellspacing. Di era modern, pengaturan visual ini sepenuhnya ditangani oleh CSS (border-collapse: collapse;).
  • Kegunaan Relevan: Tanpa tag ini, browser tidak akan bisa merender baris dan sel secara terstruktur.
<tr>

2. Tag <tr> (Table Row / Baris Tabel)

Singkatan dari *Table Row*. Tag ini digunakan untuk mendefinisikan sebuah **baris horizontal** dalam tabel.

  • Fungsi Utama: Menjadi wadah atau penampung bagi sel-sel data (<td>) maupun sel kepala (<th>) yang berderet secara horizontal.
  • Aturan Penting: Tag <tr> tidak boleh langsung diisi dengan teks biasa. Teks wajib dibungkus di dalam <th> atau <td>.
  • Kegunaan Relevan: Jumlah tag <tr> menentukan berapa banyak baris vertikal ke bawah yang dimiliki oleh tabel Anda.
<th>

3. Tag <th> (Table Header / Kepala Sel Tabel)

Singkatan dari *Table Header*. Tag ini digunakan untuk membuat sel judul atau kepala kolom/baris yang menjelaskan kategori data di bawahnya.

  • Karakteristik Visual Bawaan: Teks secara otomatis dicetak **Tebal (Bold)** dan posisinya berada di **Tengah Sel (Center Aligned)**.
  • Aksesibilitas & Semantik: Pembaca layar (*screen reader*) membaca atribut scope="col" atau scope="row" pada tag <th> untuk membacakan konteks data kepada tunanetru.
  • Kegunaan Relevan: Diletakkan di baris paling atas (atau kolom paling kiri) sebagai petunjuk nama atribut data (misal: "No", "Nama Siswa", "Nilai").
<td>

4. Tag <td> (Table Data / Sel Data Tabel)

Singkatan dari *Table Data*. Tag ini merupakan sel standar yang menampung isi/nilai aktual dari tabel tersebut.

  • Karakteristik Visual Bawaan: Teks dicetak dengan ketebalan **Normal** dan posisinya rata **Kiri (Left Aligned)**.
  • Fleksibilitas Konten: Di dalam sel <td>, Anda tidak hanya bisa memasukkan teks, tetapi juga gambar (<img>), link (<a>), tombol, bahkan tabel lain (*nested table*).
  • Kegunaan Relevan: Menyimpan nilai spesifik untuk setiap entitas baris dan kolom.

3. Perbandingan Mendalam: <th> vs <td>

Kriteria Perbandingan Tag <th> (Table Header) Tag <td> (Table Data)
Tujuan Penggunaan Mendefinisikan Judul Kolom / Baris. Mendefinisikan Isi Data Aktual.
Tampilan Default (Browser) Teks Tebal (Bold) & Rata Tengah (Center) Teks Normal & Rata Kiri (Left)
Posisi Umum Baris pertama tabel (<thead>) atau kolom pertama. Baris-baris data (<tbody>).
Dampak SEO & Accessibility Sangat Tinggi (Membantu Screen Reader memahami konteks). Netral (Hanya berisi nilai data).

4. Fitur Penggabungan Sel: Colspan dan Rowspan

Dalam pembuatan tabel nyata, seringkali kita perlu menggabungkan beberapa sel menjadi satu. Hal ini dilakukan menggunakan dua atribut khusus yang dipasang pada tag <th> atau <td>:

colspan="jumlah_kolom"

**Column Span:** Menggabungkan sel secara **Horizontal** (ke samping kanan). Nilai angka menentukan berapa kolom yang dilebur menjadi satu.

rowspan="jumlah_baris"

**Row Span:** Menggabungkan sel secara **Vertikal** (ke bawah). Nilai angka menentukan berapa baris yang dilebur menjadi satu.

💡 **Petunjuk Belajar:** Di bawah ini terdapat contoh sintaksis dasar potongan kode untuk masing-masing tag, diikuti oleh penjelasan cara kerjanya secara mendetail.

1. Penggunaan Basic Tag <table> dan <tr> Struktur Dasar

Kode HTML:

<!-- Mendefinisikan Wadah Tabel dengan Border -->
<table border="1">
  <!-- Baris Pertama -->
  <tr>
    <!-- Isi sel diletakkan di sini -->
  </tr>
  <!-- Baris Kedua -->
  <tr>
    <!-- Isi sel diletakkan di sini -->
  </tr>
</table>

Penjelasan Kode:

1. Tag <table border="1"> membuka area tabel dan memberikan garis tepi selebar 1 piksel.

2. Setiap pasang <tr>...</tr> merepresentasikan **satu baris baru** dari atas ke bawah.

3. Kode di atas menyiapkan 2 baris kosong siap diisi sel.

2. Penerapan <th> untuk Judul dan <td> untuk Data Isi Sel

Kode HTML:

<table border="1">
  <!-- Baris Header (Judul Kolom) -->
  <tr>
    <th>NIM</th>
    <th>Nama Lengkap</th>
    <th>Jurusan</th>
  </tr>
  <!-- Baris Data Pertama -->
  <tr>
    <td>220101</td>
    <td>Budi Santoso</td>
    <td>Teknik Informatika</td>
  </tr>
</table>

Penjelasan Kode:

1. Baris pertama berisi 3 buah tag <th>. Teks "NIM", "Nama Lengkap", dan "Jurusan" akan otomatis tebal dan di tengah.

2. Baris kedua berisi 3 buah tag <td>. Teks "220101", "Budi Santoso", dan "Teknik Informatika" akan ditampilkan biasa rata kiri.

3. Jumlah sel pada baris data harus sama dengan jumlah sel pada baris header agar tabel simetris.

3. Penerapan Atribut Penggabungan Sel (Colspan & Rowspan) Advanced

Kode HTML:

<table border="1">
  <tr>
    <!-- Merentang 2 Kolom ke Samping -->
    <th colspan="2">Nama Lengkap</th>
    <th>Nilai</th>
  </tr>
  <tr>
    <td>Ahmad</td>
    <td>Dhani</td>
    <!-- Merentang 2 Baris ke Bawah -->
    <td rowspan="2">A (Sempurna)</td>
  </tr>
  <tr>
    <td>Siti</td>
    <td>Nurhaliza</td>
  </tr>
</table>

Penjelasan Kode:

1. <th colspan="2"> menggabungkan kolom Nama Depan dan Nama Belakang di bawah satu header bernama "Nama Lengkap".

2. <td rowspan="2"> membuat sel nilai "A (Sempurna)" memanjang vertikal mencakup baris Ahmad dan baris Siti.

3. **Perhatikan:** Pada baris ketiga, kita hanya menuliskan 2 sel <td> karena sel ketiga sudah "dimakan" oleh rowspan="2" dari baris sebelumnya.

Penugasan Praktikum Mandiri (Studi Kasus Siswa)

Kerjakan 3 tugas proyek tabel berikut di text editor (VS Code / Notepad) dan kumpulkan file HTML Anda.

Studi Kasus 1

Jadwal Pelajaran Mingguan

Buatlah file jadwal.html yang menampilkan jadwal sekolah dari Hari Senin hingga Jumat.

  • Gunakan <th> untuk nama Hari dan Jam Pelajaran.
  • Gunakan colspan untuk sel **ISTIRAHAT** yang memanjang horizontal di tengah jam.
Target Kompetensi: Pemahaman dasar <table>, <tr>, <th>, <td>, dan Colspan sederhana.
Studi Kasus 2

Laporan Penjualan Toko

Buatlah file penjualan.html rekap penjualan elektronik bulanan.

  • Kolom: No, Kode Barang, Nama Barang, Kategori, Harga, Jumlah Terjual, Total.
  • Gunakan rowspan untuk menggabungkan nama Kategori barang yang sama.
  • Gunakan colspan di baris paling bawah untuk menghitung **Grand Total Penjualan**.
Target Kompetensi: Kombinasi Colspan dan Rowspan pada tabel finansial kompleks.
Studi Kasus 3 (Tantangan)

Transkrip Nilai Berwarna

Buatlah file transkrip.html dengan struktur semantik lengkap (<thead>, <tbody>, <tfoot>).

  • Header bertingkat (Header Mata Pelajaran membawahi Nilai Tugas, UTS, UAS).
  • Berikan warna latar (*zebra striping*) berselang-seling pada baris menggunakan CSS.
Target Kompetensi: Semantik HTML5 + Integrasi Estetika CSS Modern.
